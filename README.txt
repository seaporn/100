# Авто План — PWA

Это PWA-версия приложения для накопления на авто.

Файлы:
- index.html — приложение
- manifest.json — настройки PWA
- service-worker.js — офлайн-кэш
- icon-180.png, icon-192.png, icon-512.png — иконки

Как запустить локально на Windows:
1. Распакуй ZIP.
2. Открой папку в VS Code.
3. Установи расширение Live Server.
4. Нажми правой кнопкой на index.html → Open with Live Server.

Как поставить на iPhone как приложение:
1. Выложи папку на HTTPS-хостинг, например GitHub Pages, Netlify или Cloudflare Pages.
2. Открой ссылку на iPhone в Safari.
3. Нажми “Поделиться”.
4. Нажми “На экран Домой”.
5. Назови “Авто План”.
6. Нажми “Добавить”.

Важно:
- Если открыть просто локальный HTML-файл, PWA и офлайн-кэш могут не работать.
- Для установки на iPhone нужен сайт по HTTPS.
- Прогресс хранится локально на устройстве в localStorage.
